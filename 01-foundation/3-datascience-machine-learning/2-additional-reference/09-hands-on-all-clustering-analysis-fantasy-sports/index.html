    1. Overview

    Fantasy sports are online gaming platforms where participants draft and manage virtual teams of real professional players. Points are assigned based on actual match performance, and users compete to maximize their score.

    • The fantasy sports market was valued at \(18.6 billion in 2019** and is projected to reach **\)48.6 billion by 2027.
    • Football (soccer) dominates the market, with over 8 million participants worldwide.
    • Growth is driven by digitalization, smartphone adoption, and global accessibility.

    Objective:
    OnSports, a leading fantasy sports platform, seeks to analyze past season player performance to determine starting prices for the new English Premier League season. By performing cluster analysis, we aim to segment players by potential and performance patterns, helping set fair player valuations.

    2. Dataset Description

    The dataset contains player statistics from the previous football season.

    Features:
    - Player_Name – Name of the player
    - Club – Player's football club
    - Position – Playing position (e.g., Forward, Midfielder, Defender, Goalkeeper)
    - Goals_Scored – Goals scored in the season
    - Assists – Assists provided
    - Total_Points – Total fantasy points earned
    - Minutes – Total minutes played
    - Goals_Conceded – Goals conceded
    - Creativity – Score reflecting ability to create scoring opportunities
    - Influence – Score reflecting overall match impact
    - Threat – Score estimating likelihood of scoring goals
    - Bonus – Bonus points awarded in matches
    - Clean_Sheets – Matches without conceding a goal

    3. Methodology

    The analysis was conducted in the following steps:

    1. Data Cleaning & Preprocessing
    2. Remove missing or inconsistent values.

    3. Normalize statistical features for clustering.

    4. Feature Selection

    5. Key performance indicators such as Goals_Scored, Assists, Total_Points, Creativity, Influence, and Threat were prioritized.

    6. Clustering Techniques

    7. K-Means Clustering: Identify groups of players with similar overall performance.
    8. K-Medoids (PAM): Reduce sensitivity to outliers.

    9. Gaussian Mixture Models (GMM): Soft clustering for probabilistic player grouping.

    10. Validation

    11. Optimal cluster selection using Elbow Method and Silhouette Score.

    4. Python Implementation

    🔹 K-Means Clustering Example

    import pandas as pd
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

# Load dataset
data = pd.read_csv("fantasy_players.csv")

# Select features
X = data[['Goals_Scored', 'Assists', 'Total_Points', 'Creativity', 'Influence', 'Threat']]

# Apply KMeans
kmeans = KMeans(n_clusters=4, random_state=42)
data['Cluster'] = kmeans.fit_predict(X)

# Plot clusters
plt.scatter(X['Goals_Scored'], X['Total_Points'], c=data['Cluster'], cmap='viridis')
plt.xlabel("Goals Scored")
plt.ylabel("Total Fantasy Points")
plt.title("K-Means Clustering of Players")
plt.show()

    🔹 Gaussian Mixture Model (GMM) Example

    from sklearn.mixture import GaussianMixture

# Apply GMM
gmm = GaussianMixture(n_components=4, random_state=42)
data['GMM_Cluster'] = gmm.fit_predict(X)

# Plot GMM clusters
plt.scatter(X['Goals_Scored'], X['Total_Points'], c=data['GMM_Cluster'], cmap='plasma')
plt.xlabel("Goals Scored")
plt.ylabel("Total Fantasy Points")
plt.title("GMM Clustering of Players")
plt.show()

    5. Insights & Interpretation

    • Cluster 1: High-performing forwards with strong goal and threat scores → premium pricing.
    • Cluster 2: Midfielders with high assists and creativity → mid-to-high pricing.
    • Cluster 3: Defensive players with clean sheets and influence → moderate pricing.
    • Cluster 4: Low engagement/bench players with minimal contributions → budget pricing.

    This segmentation helps identify marketable stars, reliable performers, and undervalued assets in fantasy sports.
