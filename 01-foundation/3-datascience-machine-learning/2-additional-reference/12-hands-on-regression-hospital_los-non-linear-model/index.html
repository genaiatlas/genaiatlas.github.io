    Project Context and Objectives

    Healthcare resource allocation represents a critical challenge amplified during the COVID-19 pandemic. This tutorial addresses a fundamental problem: predicting patient length of stay (LOS) to optimize hospital resource management. The HealthPlus hospital scenario provides a realistic framework for understanding how predictive modeling can directly impact operational efficiency and patient outcomes.

    Business Problem Definition

    HealthPlus hospital faces significant revenue losses and suboptimal patient outcomes due to inefficient resource allocation. The core challenge involves predicting patient LOS during admission to enable:

    • Proactive resource planning for beds, equipment, and staff
    • Improved patient flow management throughout the hospital system
    • Cost optimization through better capacity utilization
    • Enhanced care quality via appropriate resource allocation

    Methodological Approach

    This analysis employs a systematic regression modeling approach:

    1. Comprehensive data exploration to understand patient demographics and admission patterns
    2. Statistical correlation analysis to identify key predictive relationships
    3. Multiple regression techniques including regularization methods
    4. Feature selection optimization to balance model complexity and performance
    5. Critical performance evaluation across multiple metrics

    The tutorial demonstrates how statistical modeling translates into actionable healthcare insights while maintaining analytical rigor.

    Data Overview and Structure

    Dataset Characteristics

    The healthcare dataset contains 500,000 patient records with 15 features capturing admission-time information. This substantial sample size enables robust statistical inference while presenting computational considerations for model training.

    Key Dataset Properties: - Scale: 500,000 patients × 15 features - Completeness: No missing values detected - Scope: Admitted patients only (excludes outpatient visits) - Temporal Range: Cross-sectional admission data

    Feature Categories and Clinical Relevance

    Patient Demographics: - Age groups and gender distribution - Previous health conditions profile

    Admission Context: - Admission type (trauma, emergency, urgent) - Severity classification (extreme, moderate, minor) - Insurance status and deposit amounts

    Hospital Infrastructure: - Available rooms and staff capacity - Department and ward assignments - Attending physician information

    Data Quality Assessment

    The analysis reveals several important characteristics:

    Strengths: - Complete data with no missing values - Large sample size supporting statistical power - Comprehensive feature set covering clinical and operational factors

    Limitations: - Patient ID shows multiple admissions (up to 21 per patient), potentially introducing dependency - Cross-sectional design limits causal inference - No temporal tracking of patient progression during stay

    Critical Insight: The maximum 21 admissions per patient suggests either chronic conditions requiring frequent hospitalization or data collection spanning multiple years. This repeat patient pattern requires careful consideration in model validation to avoid data leakage.

    Data Preparation Strategy

    Categorical Encoding Approach

    The preprocessing pipeline employs one-hot encoding for categorical variables, creating 42 total features from the original 15. This expansion reflects the categorical nature of healthcare data while maintaining interpretability.

    Encoding Decisions: - Drop-first strategy: Prevents multicollinearity in dummy variables - Feature expansion: 15 → 42 features post-encoding - Memory considerations: 500,000 × 42 matrix requires efficient processing

    Train-Test Split Strategy

    Split Configuration: - Training set: 80% (400,000 patients) - Test set: 20% (100,000 patients) - Random state: Fixed for reproducibility - Stratification: Not applied (continuous target variable)

    Rationale: The large dataset size supports this split ratio while maintaining substantial test set size for robust evaluation. The absence of temporal ordering allows random splitting without data leakage concerns.

    Data Preparation Limitations

    Considerations: - Patient independence assumption: Multiple admissions per patient may violate independence - Feature scaling: Not applied (standardization may be needed for regularization) - Categorical balance: Some categories have low representation, potentially affecting model stability

    When Regularization Would Help: - Smaller dataset sizes (high variance risk) - Continuous feature dominance (potential multicollinearity) - Many irrelevant features (need for feature selection)

    5. Linear Regression Implementation

    Performance Metrics Framework

    def adj_r2_score(predictors, targets, predictions):
    """
    Calculate adjusted R-squared for regression models

    Formula: 1 - ((1 - R²) * (n - 1) / (n - k - 1))
    where n = sample size, k = number of predictors
    """
    r2 = r2_score(targets, predictions)
    n = predictors.shape[0]  # Number of observations
    k = predictors.shape[1]  # Number of predictors
    return 1 - ((1 - r2) * (n - 1) / (n - k - 1))

def mape_score(targets, predictions):
    """
    Mean Absolute Percentage Error calculation

    Formula: mean(|actual - predicted| / |actual|) * 100
    """
    return np.mean(np.abs(targets - predictions) / targets) * 100

def model_performance_regression(model, predictors, target):
    """
    Comprehensive regression model evaluation

    Returns:
    --------
    DataFrame with RMSE, MAE, R-squared, Adjusted R-squared, MAPE
    """
    pred = model.predict(predictors)

    # Core metrics calculation
    r2 = r2_score(target, pred)
    adjr2 = adj_r2_score(predictors, target, pred)
    rmse = np.sqrt(mean_squared_error(target, pred))
    mae = mean_absolute_error(target, pred)
    mape = mape_score(target, pred)

    # Results dataframe
    df_perf = pd.DataFrame({
        "RMSE": rmse,
        "MAE": mae,
        "R-squared": r2,
        "Adj. R-squared": adjr2,
        "MAPE": mape,
    }, index=[0])

    return df_perf

    Metric Implementation Details: - Adjusted R²: Penalizes model complexity, essential for feature selection - RMSE vs MAE: RMSE penalizes large errors more heavily than MAE - MAPE: Provides interpretable percentage error for business stakeholders - DataFrame output: Consistent format for model comparison

    Mathematical Foundation: Linear regression solves: β = (X^T X)^(-1) X^T y

    Implementation Advantages: - Analytical solution: No iterative optimization required - Global optimum: Guaranteed optimal solution for linear objectives - Coefficient interpretation: Direct relationship between features and target

    Statistical Significance Testing

    from scipy import stats

def prediction_confidence_interval(model, X, alpha=0.05):
    """
    Calculate prediction confidence intervals for linear regression

    Parameters:
    -----------
    model : sklearn LinearRegression
        Fitted linear regression model
    X : array-like
        Feature matrix for predictions
    alpha : float
        Significance level (default 0.05 for 95% CI)

    Returns:
    --------
    tuple : (predictions, lower_bound, upper_bound)
    """
    predictions = model.predict(X)

    # Calculate residual standard error
    residuals = y_train - model.predict(x_train)
    mse = np.mean(residuals ** 2)
    se = np.sqrt(mse)

    # t-statistic for confidence interval
    t_val = stats.t.ppf(1 - alpha/2, df=len(y_train) - X.shape[1] - 1)

    # Standard error of prediction
    se_pred = se * np.sqrt(1 + np.diag(X @ np.linalg.inv(x_train.T @ x_train) @ X.T))

    # Confidence intervals
    lower_bound = predictions - t_val * se_pred
    upper_bound = predictions + t_val * se_pred

    return predictions, lower_bound, upper_bound

    Residual Analysis Implementation

    def residual_analysis(model, X_train, y_train, X_test, y_test):
    """
    Comprehensive residual analysis for regression diagnostics

    Parameters:
    -----------
    model : fitted sklearn model
    X_train, y_train : training data
    X_test, y_test : testing data

    Returns:
    --------
    dict : Residual analysis results
    """
    # Generate predictions
    train_pred = model.predict(X_train)
    test_pred = model.predict(X_test)

    # Calculate residuals
    train_residuals = y_train - train_pred
    test_residuals = y_test - test_pred

    # Residual analysis
    analysis = {
        'train_residual_mean': train_residuals.mean(),
        'test_residual_mean': test_residuals.mean(),
        'train_residual_std': train_residuals.std(),
        'test_residual_std': test_residuals.std(),
        'train_residuals': train_residuals,
        'test_residuals': test_residuals,
    }

    # Visualization
    fig, axes = plt.subplots(2, 2, figsize=(15, 10))

    # Residuals vs fitted
    axes[0, 0].scatter(train_pred, train_residuals, alpha=0.5)
    axes[0, 0].axhline(y=0, color='red', linestyle='--')
    axes[0, 0].set_title('Residuals vs Fitted (Training)')
    axes[0, 0].set_xlabel('Fitted Values')
    axes[0, 0].set_ylabel('Residuals')

    # QQ plot for normality
    stats.probplot(train_residuals, dist="norm", plot=axes[0, 1])
    axes[0, 1].set_title('Normal Q-Q Plot (Training Residuals)')

    # Histogram of residuals
    axes[1, 0].hist(train_residuals, bins=50, alpha=0.7)
    axes[1, 0].set_title('Distribution of Training Residuals')
    axes[1, 0].set_xlabel('Residuals')
    axes[1, 0].set_ylabel('Frequency')

    # Residuals vs predicted (test set)
    axes[1, 1].scatter(test_pred, test_residuals, alpha=0.5, color='orange')
    axes[1, 1].axhline(y=0, color='red', linestyle='--')
    axes[1, 1].set_title('Residuals vs Fitted (Testing)')
    axes[1, 1].set_xlabel('Fitted Values')
    axes[1, 1].set_ylabel('Residuals')

    plt.tight_layout()
    plt.show()

    return analysis

# Example usage

    def create_production_pipeline(selected_features, model_params=None):

    Create production-ready prediction pipeline

    Parameters:
    -----------
    selected_features : list
        Feature names selected through feature selection
    model_params : dict
        Model hyperparameters if needed

    from sklearn.pipeline import Pipeline

    if model_params is None:
