    1. Overview

    The discovery of DNA and its role in storing biological information revolutionized biology. DNA, represented using the alphabet A, C, G, and T, encodes genetic instructions through sequences called codons. This study demonstrates how unsupervised learning techniques, specifically PCA and K-Means clustering, can reveal the codon structure in bacterial DNA without prior labeling.

    The focus is on the genomic sequence of Caulobacter Crescentus, revealing the underlying 3-letter codon structure using data science methods.

    2. Dataset Description

    • Source: DNA sequence fragment of Caulobacter Crescentus
    • File format: .fa (FASTA format)
    • Size: ~300,000 base pairs
    • Structure: Continuous string of A, C, G, T without spaces
    • Processing:
    • Sequence split into non-overlapping 300 bp segments
    • Generated frequency tables for word lengths \( M = 1, 2, 3, 4 \)
    • Features: \( 4^M \) for each M

    3. Methodology

    1. Sequence Segmentation:
    2. Break sequence into fixed-length substrings.
    3. Feature Extraction:
    4. For each \( M \), count occurrences of each possible word (e.g., for \( M=2 \), 16 features).
    5. Normalization:
    6. Standardize each feature by subtracting the mean and dividing by standard deviation.
    7. Dimensionality Reduction:
    8. Apply PCA to visualize patterns.
    9. Clustering:
    10. Apply K-Means in the high-dimensional space, then visualize results in PCA-reduced space.

    4. Python Implementation

    from sklearn.decomposition import PCA
import pandas as pd

pca = PCA(n_components=2)
pCompTables = {}

for i in range(1,5):
    pca.fit(normFreqTables[i])
    pCompTables[i] = pd.DataFrame(
        pca.transform(normFreqTables[i])[:, 0:2], 
        columns=['pc1', 'pc2']
    )
    print(f'Explained variance for {i} letters: {pca.explained_variance_ratio_.sum()}')

print(pCompTables[2].head())

    5. Insights & Interpretation

    • For \( M=1, 2, 4 \): Data forms a single dense cluster.
    • For \( M=3 \): Clear structure emerges, with six lobes (3 reading frames forward, 3 backward) and a central blob representing non-coding regions.
    • Codons are confirmed as 3-letter words, encoding amino acids.
    • PCA effectively highlights these structures, and K-Means confirms distinct groupings.

    6.Understanding PC1 and PC2 in PCA

    When performing Principal Component Analysis (PCA), the goal is to reduce high-dimensional data into a smaller set of dimensions while retaining as much of the variation (information) as possible.

    In this example, we use:

    pca = PCA(n_components=2)

    This means we are projecting our data onto two new orthogonal axes:

    • PC1 (Principal Component 1) → Captures the largest variance in the data.
    • PC2 (Principal Component 2) → Captures the second-largest variance, orthogonal to PC1.

    By keeping only 2 components, we can:

    1. Visualize the data in a 2D plot (PC1 vs PC2).
    2. Preserve most of the important variation while removing noise.

    Python Example

    pca = PCA(n_components=2)

pCompTables = {}

for i in range(1,5):
    pca.fit(normFreqTables[i])
    pComponents = pca.transform(normFreqTables[i])
    # for each word size, store only PC1 and PC2 in a DataFrame
    pCompTables[i] = pd.DataFrame(pComponents[:, [0,1]], columns = ['pc1', 'pc2'])
    print('Explained variance for ' + str(i) + ' letters: ' + str(pca.explained_variance_ratio_.sum()))

print(pCompTables[2].head())

    Why PC1 and PC2?

    • PC1: Finds the direction in the dataset that explains the most variance.
    • PC2: Finds the next most informative direction, constrained to be orthogonal to PC1.
    • By choosing 2 components, we balance interpretability and variance preservation.
    • These components are often used for visualizing high-dimensional data in 2D.

    7. Use Case Impact

    • Validates biological discovery of codons using purely computational unsupervised methods.
    • Demonstrates applicability of ML in genomics.
    • Provides a workflow adaptable to other genomic datasets.
