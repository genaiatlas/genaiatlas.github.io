    What This Project Is

    • A hands‑on topic modeling case study using Latent Dirichlet Allocation (LDA) on a corpus of academic papers.
    • You’ll see how to move from raw text → numeric features → probabilistic topics → human‑readable insights.
    • Two styles are common in this folder:
    • A practical scikit‑learn LDA runner (fast, good defaults).
    • (Optionally) a more educational SVI LDA implementation to see how the math runs step‑by‑step.

    How to Run Locally

    ↩ Back to Top
    The core script is run_lda.py (see code below). Typical runs:

    # default (5 topics, unigrams)
python run_lda.py

# more topics
python run_lda.py --topics 8

# include bigrams
python run_lda.py --ngrams 2

# export artifacts
python run_lda.py --topics 8 --ngrams 2 \
  --save-csv lda_terms_8_bigram.csv \
  --save-doc-topics doc_topic_scores.csv

# optional visualization (if pyLDAvis is installed in your env)
python run_lda.py --topics 8 --ngrams 2 --out mit_topics.html

    Concepts You’ll Learn

    ↩ Back to Top
    LDA (Latent Dirichlet Allocation): an unsupervised probabilistic model where - each document is a mixture of topics, - each topic is a mixture of words.

    Why it’s useful: It surfaces latent themes in large text corpora, helping you search, cluster, summarize, and discover.

    Variational Inference (VI): an optimization-based approach to approximate the intractable posterior in LDA. - You posit a simpler family (variational distribution), then optimize it to be close to the true posterior. - Stochastic/online flavors process mini-batches for scalability.

    Pipeline: From Raw Text to Topics

    ↩ Back to Top
    1. Load Data: read data/papers (JSON list of documents). 2. Preprocess: lowercasing, tokenization, removing stopwords, optionally include bigrams. 3. Vectorize: CountVectorizer → Document‑Term Matrix (rows=docs, cols=terms, values=counts). 4. Fit LDA: learn topic distributions over words and document distributions over topics. 5. Inspect: print top words, view top documents per topic, write CSVs. 6. Visualize (optional): pyLDAvis to explore the learned topics interactively. 7. Iterate: adjust K, pruning thresholds, n‑grams; compare results.

    “Compilation” vs “Execution” in ML Projects

    There’s no C/C++ style compilation here. Instead, think in terms of data/ML pipeline construction:

    • Build phase (akin to compilation): Set up dependencies, load data, construct features (vectorizers), define model and hyperparameters.
    • Fit/Train phase: Run the optimizer/VI to estimate hidden variables and parameters.
    • Evaluation/Export phase (execution artifacts): Print topics, save CSVs, render HTML viz.
    • Reproducibility: Lock random seeds and versions to “re‑build” the same model later.

    This “build → fit → evaluate → export” loop is the ML analog of compile → link → execute.

    Hyperparameters & Practical Tips

    • --topics (K): higher K = finer granularity; too high fragments themes.
    • --ngrams: set to 2 to include bigrams; helpful for phrases like “neural network”.
    • --max_df / --min_df: prune ubiquitous/rare terms for cleaner topics.
    • --max_features: cap vocabulary if memory is tight.
    • --words-per-topic & --csv-words: control output verbosity.
    • Sanity checks: read the top documents for each topic; if they don’t make sense, tune pruning or K.

    Artifacts & How to Read Them

    • Console topics: a quick glance at themes (top N terms).
    • lda_top_terms.csv (--save-csv): ranked words per topic for reports.
    • doc_topic_scores.csv (--save-doc-topics): topic mixture per document for filtering/ranking.
    • mit_topics.html: interactive topic map (if pyLDAvis available).

    Case Study - Data Analysis with Human-Generated Text/svilda.py

    import random
import numpy as n
from scipy.special import psi
from nltk.tokenize import wordpunct_tokenize

meanchangethresh = 1e-3

def dirichlet_expectation(alpha):
    '''see onlineldavb.py by Blei et al'''
    if (len(alpha.shape) == 1):
        return (psi(alpha) - psi(n.sum(alpha)))
    return (psi(alpha) - psi(n.sum(alpha, 1))[:, n.newaxis])

class SVILDA():
    def __init__(self, vocab, K, D, alpha, eta, tau, kappa, iterations):
        self._vocab = vocab
        self._V = len(vocab)
        self._K = K
        self._D = D
        self._alpha = alpha
        self._eta = eta
        self._tau = tau+1
        self._kappa = kappa
        self._lambda = 1* n.random.gamma(100., 1./100., (self._K, self._V))
        self._Elogbeta = dirichlet_expectation(self._lambda)
        self._expElogbeta = n.exp(self._Elogbeta)
        self.ct = 0
        self._iterations = iterations

    def updateLocal(self, doc): #word_dn is an indicator variable with dimension V
        (wordids, wordcts) = doc
        batchD = len(wordids)

        # Initialize the variational distribution q(theta|gamma) for
        # the mini-batch
        gamma = 1*n.random.gamma(100., 1./100., (batchD, self._K))
        Elogtheta = dirichlet_expectation(gamma)
        expElogtheta = n.exp(Elogtheta)

        sstats = n.zeros(self._lambda.shape)
        # Now, for each document d update that document's gamma and phi
        it = 0
        meanchange = 0
        for d in range(0, batchD):
            # These are mostly just shorthand (but might help cache locality)
            ids = wordids[d]
            cts = wordcts[d]
            gammad = gamma[d, :]
            Elogthetad = Elogtheta[d, :]
            expElogthetad = expElogtheta[d, :]
            expElogbetad = self._expElogbeta[:, ids]
            # The optimal phi_{dwk} is proportional to 
            # expElogthetad_k * expElogbetad_w. phinorm is the normalizer.
            phinorm = n.dot(expElogthetad, expElogbetad) + 1e-100
            # Iterate between gamma and phi until convergence
            for it in range(0, 100):
                lastgamma = gammad
                # We represent phi implicitly to save memory and time.
                # Substituting the value of the optimal phi back into
                # the update for gamma gives this update. Cf. Lee&Seung 2001.
                gammad = self._alpha + n.multiply(expElogthetad, expElogbetad) * cts / phinorm
                Elogthetad = dirichlet_expectation(gammad)
                expElogthetad = n.exp(Elogthetad)
                phinorm = n.dot(expElogthetad, expElogbetad) + 1e-100
                # If gamma hasn't changed much, we're done.
                meanchange = n.mean(abs(gammad - lastgamma))
                if (meanchange < meanchangethresh):
                    break
            gamma[d, :] = gammad
            # Contribution of document d to the expected sufficient
            # statistics for the M step.
            sstats[:, ids] += n.multiply(expElogthetad, expElogbetad) * cts / phinorm

        # This step finishes computing the sufficient statistics for the
        # M step, so that
        # sstats[k, w] = \sum_d n_{dw} * phi_{dwk} 
        # = \sum_d n_{dw} * exp{Elogtheta_{dk} + Elogbeta_{kw}} / phinorm_{dw}.

        return gamma, sstats

    def updateGlobal(self, sstats, doc):
            # print 'updating global parameters'
        (words, counts) = doc

        rhot = (self.ct + self._tau) **(-self._kappa)

        self._lambda = self._lambda * (1-rhot) + rhot * (self._eta + self._D * sstats / len(words))

        self._Elogbeta = dirichlet_expectation(self._lambda)
        self._expElogbeta = n.exp(self._Elogbeta)


    def runSVI(self, doc_vecs):

        for i in range(self._iterations):            
            randint = random.randint(0, self._D-1)
            if (i%100)==0: 
                print("ITERATION", i, " running document number ", randint)

            doc = doc_vecs[randint]
            gamma_d, sstats = self.updateLocal(doc)
            self.updateGlobal(sstats, doc)
            self.ct += 1

    Enhanced Runner We Used (run_lda.py)

    The enhanced runner you executed in this project (with flags for CSV, doc‑topic, top‑docs, etc.):

    # Enhanced run_lda.py (used in your successful runs)
# - optional pyLDAvis
# - --save-csv, --save-doc-topics
# - --top-docs with de-duplication
# - words-per-topic controls
import os, json, argparse, csv, numpy as np
from sklearn.decomposition import LatentDirichletAllocation
from sklearn.feature_extraction.text import CountVectorizer
HAS_VIZ = True
try:
    import pyLDAvis, pyLDAvis.sklearn
except Exception:
    HAS_VIZ = False
def topk_unique(scores, k, texts, snippet_len=120):
    if k <= 0: return []
    k = min(k, scores.shape[0])
    idx = np.argpartition(scores, -k)[-k:]
    idx = idx[np.argsort(scores[idx])][::-1]
    seen, out = set(), []
    for i in idx:
        key = texts[i][:snippet_len]
        if key not in seen:
            seen.add(key); out.append(i)
        if len(out) == k: break
    return out
def main():
    p = argparse.ArgumentParser()
    p.add_argument("--topics", type=int, default=5)
    p.add_argument("--max_df", type=float, default=0.95)
    p.add_argument("--min_df", type=int, default=2)
    p.add_argument("--max_features", type=int, default=20000)
    p.add_argument("--ngrams", type=int, choices=[1,2], default=1)
    p.add_argument("--words-per-topic", type=int, default=12)
    p.add_argument("--csv-words", type=int, default=20)
    p.add_argument("--save-csv", default="")
    p.add_argument("--top-docs", type=int, default=0)
    p.add_argument("--save-doc-topics", default="")
    p.add_argument("--out", default="lda_topics.html")
    p.add_argument("--mds", choices=["mmds","tsne"], default="mmds")
    args = p.parse_args()
    ROOT = os.path.dirname(__file__)
    data_file = os.path.join(ROOT, "data", "papers")
    if not os.path.exists(data_file):
        raise FileNotFoundError(f"Missing data file: {data_file}")
    with open(data_file, "r") as f:
        papers = json.load(f)
    vectorizer = CountVectorizer(
        max_df=args.max_df, min_df=args.min_df, max_features=args.max_features,
        stop_words="english", ngram_range=(1, args.ngrams)
    )
    X = vectorizer.fit_transform(papers)
    lda = LatentDirichletAllocation(n_components=args.topics, learning_method="batch", random_state=0).fit(X)
    feature_names = vectorizer.get_feature_names_out()
    for k, topic in enumerate(lda.components_):
        top = topic.argsort()[-args.words_per_topic:][::-1]  # bug to remind this is illustrative
        terms = ", ".join(feature_names[i] for i in top)
        print(f"\\nTopic {k+1}: {terms}")
    if args.save_csv:
        with open(args.save_csv, "w", newline="") as f:
            w = csv.writer(f); w.writerow(["topic","rank","term"])
            for k, topic in enumerate(lda.components_):
                top = topic.argsort()[-args.csv_words:][::-1]
                for r, i in enumerate(top, start=1):
                    w.writerow([k+1, r, feature_names[i]])
        print(f"\\nSaved topic-term CSV: {args.save_csv}")
    doc_topic = lda.transform(X)
    if args.save_doc_topics:
        with open(args.save_doc_topics, "w", newline="") as f:
            w = csv.writer(f); header = ["doc_index"]+[f"topic_{i+1}" for i in range(lda.n_components)]
            w.writerow(header)
            for i, row in enumerate(doc_topic):
                w.writerow([i]+[f"{v:.6f}" for v in row])
        print(f"Saved doc→topic CSV: {args.save_doc_topics}")
    if args.top_docs>0:
        for t in range(doc_topic.shape[1]):
            top_idx = topk_unique(doc_topic[:,t], args.top_docs, papers)
            print(f"\\nTop {args.top_docs} docs for Topic {t+1}:")
            for i in top_idx:
                snippet = papers[i][:140].replace("\\n"," ")
                print(f"  • Doc {i}: {snippet}...")
    if HAS_VIZ:
        print(f"\\nSaving interactive visualization to: {args.out}")
        vis = pyLDAvis.sklearn.prepare(lda, X, vectorizer, mds=args.mds)
        pyLDAvis.save_html(vis, args.out); print("Done.")
    else:
        print("\\n(pyLDAvis not installed in this environment; printed topics only.)")
if __name__ == "__main__":
    main()
