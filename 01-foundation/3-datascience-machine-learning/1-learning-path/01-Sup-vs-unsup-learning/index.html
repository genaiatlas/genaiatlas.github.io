    Example Scenario: Email Classification — Spam vs. Not Spam

    1. Supervised Learning

    In supervised learning, the algorithm is trained on labeled data.

    Scenario

    We have a dataset of past emails where each email is already labeled as "Spam" or "Not Spam".

    How it works

    1. Training Data:
    2. Email text → "You won a prize!" → Spam
    3. Email text → "Meeting at 10am" → Not Spam
    4. Email text → "Claim your free gift" → Spam
    5. Features extracted (word counts, sender address, links, etc.).
    6. The model learns patterns that distinguish spam from non-spam.
    7. For a new incoming email, the model predicts:
    8. "Spam" if it matches spam-like patterns.
    9. "Not Spam" otherwise.

    Real-Time Example

    • Gmail uses supervised learning with millions of labeled spam/not spam examples from user feedback.

    Python (Supervised — Logistic Regression Example)

    from sklearn.feature_extraction.text import CountVectorizer
from sklearn.linear_model import LogisticRegression

# Training Data
emails = [
    "You won a prize",
    "Meeting at 10am",
    "Claim your free gift",
    "Project deadline extended"
]
labels = [1, 0, 1, 0]  # 1 = Spam, 0 = Not Spam

# Feature Extraction
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(emails)

# Train Model
model = LogisticRegression()
model.fit(X, labels)

# Predict
test_email = ["Free tickets to the concert"]
print(model.predict(vectorizer.transform(test_email)))  # Output: [1] (Spam)

    2. Unsupervised Learning

    In unsupervised learning, the algorithm works with unlabeled data.

    Scenario

    We have a large number of past emails but no spam/not spam labels.

    How it works

    1. The model groups emails into clusters based on content similarity.
    2. After clustering:
    3. Cluster A: "You won a prize", "Claim your free gift", "Free tickets" → Likely spam.
    4. Cluster B: "Meeting at 10am", "Project deadline extended" → Likely not spam.
    5. Labels are inferred later by human inspection or heuristics.

    Real-Time Example

    • Email filtering systems can first group unknown emails, then allow humans to label clusters, speeding up the training process.

    Python (Unsupervised — KMeans Example)

    from sklearn.feature_extraction.text import CountVectorizer
from sklearn.cluster import KMeans

# Unlabeled Emails
emails = [
    "You won a prize",
    "Meeting at 10am",
    "Claim your free gift",
    "Project deadline extended"
]

# Feature Extraction
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(emails)

# Apply KMeans
kmeans = KMeans(n_clusters=2, random_state=42)
kmeans.fit(X)

# Cluster Assignments
for email, label in zip(emails, kmeans.labels_):
    print(f"{email} → Cluster {label}")

    ✅ Key Difference:
    - Supervised: Needs labeled data upfront.
    - Unsupervised: Finds patterns without labels.

    Supervised vs Unsupervised Learning — Example Scenarios

    This document presents various real-world examples of Supervised and Unsupervised learning problems, including their key components: features, labels, and the reasoning for classification.

    ↩ Back to Top

    1. Air Pollution Prediction

    Scenario:
    You measured the concentration of a certain type of air pollutant at different locations, under various weather conditions, times of day, and days of the week. Now you want to predict the air pollution concentration at a new location without additional measurements.

    Learning Type: Supervised Learning ✅

    Reasoning:
    - Features: Location, weather conditions, day, and time.
    - Label: Air pollution concentration (numerical).
    - This is a regression problem because the label is a continuous numeric value (e.g., 2000 particles/cm³ is less than 6000 particles/cm³).

    ↩ Back to Top

    2. Social Group Discovery in Offices

    Scenario:
    A researcher observed office workers over a month and recorded their interactions. The goal is to discover friendships or social groups.

    Learning Type: Unsupervised Learning ✅

    Reasoning:
    - Features: Records of interactions between people.
    - Labels: None (unknown social groups).
    - The goal is clustering people into groups based on interaction patterns.

    ↩ Back to Top

    3. Rocket Booster Lift Prediction (NASA)

    Scenario:
    NASA simulates rocket booster performance under various specifications. They want to predict simulated lift for new specifications without running full simulations.

    Learning Type: Supervised Learning ✅

    Reasoning:
    - Features: Rocket booster specifications.
    - Label: Simulated lift (numerical).
    - This is a regression task predicting a continuous variable.

    ↩ Back to Top

    4. Bird Video Compression

    Scenario:
    A small bird-monitoring camera captures video, but bandwidth is limited. The goal is to compress video before transmission.

    Learning Type: Unsupervised Learning ✅

    Reasoning:
    - Features: Pixel values over time.
    - Labels: None.
    - Uses clustering (e.g., grouping similar pixels in color and time) for compression.

    ↩ Back to Top

    5. Student Algorithm Error Analysis

    Scenario:
    In an online course, students implement an algorithm for an exercise. You want to understand the different types of errors to improve teaching.

    Learning Type: Unsupervised Learning ✅

    Reasoning:
    - Features: Student solutions and code errors.
    - Labels: None (no predefined error categories).
    - Goal is to find patterns in mistakes, possibly for adaptive learning.

    ↩ Back to Top

    6. Email Classification (Spam or Not Spam)

    Scenario:
    A dataset of emails, each labeled as spam or not spam. You want to predict whether a new email is spam.

    Learning Type: Supervised Learning ✅

    Reasoning:
    - Features: Words/phrases, metadata, and structure of the email.
    - Label: Spam or Not Spam (categorical).
    - This is a classification problem because the label is discrete with no inherent order.

    📌 Key Takeaways:
    - Supervised learning uses labeled data (features + target).
    - Unsupervised learning works with unlabeled data to find patterns, clusters, or structure.
    - Labels can be categorical (classification) or numerical (regression).
