    Introduction to Principal Component Analysis¶

    In this lecture, we will start talking about the process after you have collected large-scale datasets — what can you do with them, and how do you even start thinking about data analysis?

    We will present one particular application, but you will also get an idea about how this relates to different industries, so you can connect it to applications you care about in your own work.

    Example: Healthcare Domain¶

    Suppose we have a large set of microscopy images containing many cells, and we want to identify abnormal cells.

    Key question:
    How can we visualize this dataset to find clusters or abnormal cells?

    Given:
    - Input: \( x_1, \dots, x_n \in \mathbb{R}^D \)
    - Output: \( y_1, \dots, y_n \in \mathbb{R}^d \) where \( d \ll D \)

    Example:
    - Each cell is cropped and summarized by 100 texture features (\( D = 100 \))
    - If each cell has 10,000 pixels, then each is a point in a 10,000-dimensional space

    Humans cannot visualize such high dimensions; we typically reduce data to 2D or 3D to detect clusters that may correspond to abnormal or cancerous cells.

    ↩ Back to Top ↩ Go to Introduction to Principal Component Analysis

    Analogy: Customer Data¶

    • Imagine 100,000 customers, each with 10,000 variables (e.g., purchase history)
    • We cannot directly visualize this space
    • Dimensionality reduction to 2–3 dimensions allows identification of customer clusters for targeted marketing or analysis

    ↩ Back to Top ↩ Go to Introduction to Principal Component Analysis

    Two Dimensionality Reduction Methods¶

    1. Principal Component Analysis (PCA) — Linear projection that maximizes spread of data
    2. t-SNE — Non-linear embedding preserving local neighborhood structure

    Comparison:
    - PCA: very fast, standard first step in data exploration
    - t-SNE: slower but often better at revealing clusters

    ↩ Back to Top ↩ Go to Introduction to Principal Component Analysis

    Goal of PCA¶

    • Objective: Reduce dimensionality to a few dimensions
    • Intuition: Find the projection with the largest spread (variance)

    Example:
    - Customer dataset: 10,000 dimensions → reduce to 2 or 3
    - PCA projects data linearly from \( D \)-dimensional space to \( d \)-dimensional space

    ↩ Back to Top ↩ Go to Introduction to Principal Component Analysis

    Why Maximize Spread?¶

    Variables with little variation do not contribute much information:
    - Example: If all customers are in the US, the "country" variable adds no value in explaining purchase behavior
    - In microscopy images, ignore pixels that are identical across all cells

    Intuition: Keep directions (features) that show the largest variation to preserve meaningful information.

    ↩ Back to Top ↩ Go to Introduction to Principal Component Analysis

    Application Example: DNA Sequencing¶

    Companies like 23andMe sequence DNA and record variable positions that differ across people.
    - Dataset: each person → 100,000-dimensional vector
    - PCA applied to this dataset → projection on PC1 and PC2

    Result:
    - People cluster geographically according to their origin
    - Without using location as input, PCA recreated a map of Europe by identifying two principal components that maximize spread

    Principal Component Analysis - Covariance and Eigenvectors¶

    In this lecture, we continue exploring what Principal Component Analysis (PCA) actually does, building upon the intuition from the previous lesson.

    Definition 1: Maximize Projection Variance¶

    Start with centered data \( X \in \mathbb{R}^{n \times p} \):
    - PC1: direction of largest variance
    - PC2: perpendicular to PC1, again with largest variance
    - PC3: perpendicular to PC1 & PC2, again with largest variance

    In high-dimensional space, PCA identifies directions that vary the most. For a 2D representation, we keep only the top two directions. This way, we ignore directions with negligible variation (low information).

    ↩ Back to Top ↩ Go to Principal Component Analysis - Covariance and Eigenvectors

    Definition 2: Minimize Projection Residuals¶

    • PC1: Straight line with smallest orthogonal distance to all points
    • PC1 & PC2: Plane with smallest orthogonal distance to all points

    This view focuses on minimizing signal loss after projection. Both definitions are equivalent:
    - Definition 1 keeps the largest signal possible
    - Definition 2 removes the smallest signal possible

    ↩ Back to Top ↩ Go to Principal Component Analysis - Covariance and Eigenvectors

    Computing PCA: Covariance, Eigenvalues, and Eigenvectors¶

    Process:

    1. Compute covariance matrix:

    $$ R = \frac{1}{n} X^{\top} X $$

    1. Perform spectral decomposition:

    $$ R = V \Lambda V^{\top} $$ - \( V \): eigenvectors (principal components) - \( \Lambda \): eigenvalues (variances along PCs)

    Key points:
    - Select eigenvectors corresponding to the largest eigenvalues
    - For 2D projection: keep PC1 & PC2
    - Standard in many data analysis tasks

    ↩ Back to Top ↩ Go to Principal Component Analysis - Covariance and Eigenvectors

    Example: Eigenvector Selection¶

    • PC1 → eigenvector with largest eigenvalue
    • PC2 → eigenvector with second-largest eigenvalue
    • Visualizations are created by projecting data into the space defined by these eigenvectors

    ↩ Back to Top ↩ Go to Principal Component Analysis - Covariance and Eigenvectors

    Impact of Units in PCA¶

    Changing measurement units can alter the first principal component:
    - Measuring height in cm vs. feet changes variance magnitude, altering PCA direction
    - PCA depends on scale unless normalization is applied

    Guidelines:
    - If all variables share the same units → use covariance matrix
    - If variables have different units → use correlation matrix to normalize

    Why correlation matrix?
    - Normalizes variables so each contributes equally
    - Prevents scale differences from dominating the principal components

    We have already discussed a linear method namely PCA. Now we will discuss a non-linear method and will see the advantages of non-linear methods versus linear methods for visualizing data. Here, we will see a newer method that often performs very well for identifying clusters in our dataset, known as t-SNE.

    Key points:
    - Probabilistic approach: Places samples from high-dimensional space into low-dimensional space while preserving neighbor identities. - Goal: Original high-dimensional sample distribution ≈ low-dimensional sample distribution. - Distance Metric: Uses Kullback-Leibler divergence to measure the difference between distributions, minimizing this value. - Embedding type: Non-linear, preserving closeness and separation of points.

    The Idea¶

    We have samples (e.g., customers with high-dimensional behavior data). The aim is to map them into 2D for visualization while keeping the original distributional relationships intact.

    Distance Between Distributions¶

    • Measured with Kullback-Leibler divergence.
    • Optimization is non-convex — results depend on initialization.
    • PCA embeddings are often used for initialization.
    • Computation is heavy but preserves meaningful clusters better than linear methods.

    Advantages Over Linear Methods¶

    • Avoids crowding problem (linear projections compress distant clusters).
    • Can separate clusters that PCA would merge.

    Example: MNIST Dataset¶

    • Dataset: 1800 handwritten digit images (180 each from 0–9), resized to \(8 imes 8\) grids → 64 grayscale values.
    • PCA result: One large cluster; computation ~0.01s.
    • t-SNE result: Meaningful clusters for each digit; computation ~5.7s; initialization-dependent.

    Practical Usage¶

    • PCA: Best for quick exploration and outlier detection.
    • t-SNE: Best for identifying subgroups/clusters, though slower.

    Overview¶

    Principal Component Analysis (PCA) is a dimensionality reduction technique used in machine learning to find major patterns in datasets. It's particularly useful when:

    • You have a large number of variables (features)
    • Some variables are correlated and capture similar patterns
    • You want to reduce dimensions without losing much information

    Core Idea: Transform correlated variables into a smaller set of uncorrelated variables called principal components that capture the most important patterns in the data.

    ↩ Back to Top

    Key Concepts¶

    What are Principal Components?¶

    • Definition: Hidden patterns in data represented as vectors
    • Ordering: Ranked by importance (determined by eigenvectors)
    • Purpose: Capture maximum variance in the data with fewer dimensions

    Mathematical Foundation¶

    • Each observation can be represented as: Original Value = Mean + (Component1 × Weight1) + (Component2 × Weight2) + ...
    • Principal components are linear combinations of original features
    • Components are orthogonal (uncorrelated) to each other

    Holiday Destinations Example¶

    The Dataset¶

    Scenario: 6 people rating 4 holiday destinations (Alpine Spa, Himalayas, Hawaii, Scuba)

    Person Alpine Spa Himalayas Hawaii Scuba
    Anne 20 4 16 0
    Bill 10 2 18 10
    Chris 13 1 19 7
    Jen 1 13 7 19
    Joe 18 10 10 2
    Maggie 4 20 0 16

    Discovered Patterns¶

    Pattern 1 (Adventure): [-1, +1, -1, +1] - High values for Himalayas and Scuba (adventurous destinations)

    Pattern 2 (Mountains): [+1, +1, -1, -1] - High values for Alpine Spa and Himalayas (mountain destinations)

    Results¶

    • Dimensionality Reduction: Reduced from 4 features to 2 principal components
    • Pattern Recognition: People's preferences explained by "Adventure vs. Relaxation" and "Mountains vs. Water"
    • Clustering: Natural groups emerged (mountain lovers vs. adventure seekers)

    Real-World Applications¶

    1. Facial Recognition (Eigenfaces)¶

    • Input: Face images converted to pixel vectors
    • Process: Create "eigenfaces" (ghostly representations) as principal components
    • Output: Represent any face as linear combination of eigenfaces
    • Benefit: Compress facial data while preserving identity information

    2. Genetic Analysis¶

    • Study: 1,400 Europeans with 200,000 genetic features
    • Process: PCA reduced to 2 components and plotted on European map
    • Discovery: Genetic variations highly correlated with geography
    • Insight: People's genetic makeup reflects their geographical origin

    ↩ Back to Top

    Key Benefits¶

    1. Dimensionality Reduction¶

    • Reduce feature space without significant information loss
    • Enable processing of high-dimensional data
    • Improve computational efficiency

    2. Data Visualization¶

    • Convert high-dimensional data to 2D/3D for plotting
    • Reveal hidden patterns and clusters
    • Enable intuitive understanding of complex datasets

    3. Noise Reduction¶

    • Filter out less important variations
    • Focus on principal patterns
    • Improve signal-to-noise ratio

    4. Feature Engineering¶

    • Create meaningful composite features
    • Reduce multicollinearity
    • Prepare data for other machine learning algorithms

    ↩ Back to Top

    When to Use PCA¶

    Ideal Scenarios: - High-dimensional datasets with correlated features - Need for data visualization - Computational constraints requiring dimensionality reduction - Exploratory data analysis to understand data structure

    Considerations: - Principal components may be harder to interpret than original features - Linear transformation only (may miss non-linear patterns) - Standardization of features often required before applying PCA
