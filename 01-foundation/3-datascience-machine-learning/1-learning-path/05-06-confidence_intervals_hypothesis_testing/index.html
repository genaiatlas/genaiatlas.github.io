    Introduction

    This document explains how standard errors can be used to construct confidence intervals and perform hypothesis testing in statistical analysis. These fundamental concepts form the backbone of statistical inference, allowing researchers to make statements about population parameters based on sample data.

    ↩ Back to Top

    Confidence Intervals

    Definition and Calculation

    A confidence interval (CI) provides a range of values that likely contains the true population parameter with a specified level of confidence.

    One key point to remember is that there's a true value of θ*j (where j refers to the jth component of θ), and we're estimating this value using sample data.

    Our estimate θ̂j follows a normal distribution centered at the true value θ*j with a variance σ²j:

    θ̂j ~ N(θ*j, σ²j)

    That normal distribution has a certain standard deviation. With a probability of 95%, our estimate will be within two standard deviations of the true value:

    |error| = |θ̂j - θ*j| ≤ 2σj

    In practical terms, a 95% confidence interval is calculated as:

    [θ̂j - 2σj, θ̂j + 2σj]

    Where σj is the standard error of the estimate.

    Frequentist Interpretation

    The defining property of a confidence interval is that with a probability of 95%, the true value of the parameter is inside the confidence interval:

    P(θ*j ∈ CI) ≈ 0.95

    It's crucial to understand what this probability statement means. The true parameter θ*j is not random—it's a fixed constant. The randomness is in the confidence interval itself.

    The correct interpretation is the "frequentist" interpretation: if we were to repeat our estimation procedure many times with different data sets, about 95% of the resulting confidence intervals would contain the true parameter value.

    If we obtain a specific confidence interval, for example, CI = [2, 4], we cannot say that "θj is in there with probability 95%." This would be incorrect because θj is not random. Instead, we say that our procedure for generating confidence intervals captures the true value 95% of the time.

    Confidence Levels

    There's nothing special about using 95% for confidence intervals. We could also use a 99% confidence interval, which would be wider. Instead of extending 2 standard deviations from the estimate, a 99% confidence interval would extend further (approximately 2.58 standard deviations), making it more likely to capture the true parameter value but less precise.

    Hypothesis Testing

    Null Hypothesis

    Hypothesis testing allows us to assess whether the data supports a specific claim about a parameter. A common hypothesis might be that a specific coefficient equals zero:

    H₀: θ*j = 0

    For example, we might hypothesize that the coefficient associated with newspaper advertisement spending has no effect on sales (i.e., θ*j = 0).

    This is called the null hypothesis. It's termed "null" in the sense that nothing is happening under this hypothesis (no effect), and it serves as the default assumption.

    The Wald Test

    Error Rates

    When testing hypotheses, we might make mistakes. Suppose the true value is θ*j = 0, but we reject this hypothesis. How likely is this error?

    This error occurs when our confidence interval doesn't contain the true value of 0. By definition of a 95% confidence interval, this happens with probability 5%:

    P(reject | θj = 0) = P(CI "misses" 0 | θj = 0) ≈ 5%

    This 5% is often called the significance level, or Type I error rate, typically denoted by α.

    p-values

    Another approach to hypothesis testing involves calculating p-values. The p-value represents the probability of observing a test statistic as extreme as, or more extreme than, the one observed, assuming the null hypothesis is true.

    For testing H₀: θj = 0, the p-value is the probability of getting an estimate at least as far from 0 as our observed θ̂j, under the assumption that θj = 0.

    If the p-value is less than 0.05 (or another chosen significance level), we reject the null hypothesis. This indicates that the observed data would be highly unlikely if the null hypothesis were true.

    It's important to note that p-values can be misinterpreted. A p-value is not the probability that the null hypothesis is true, nor is it the probability of making an error by rejecting the null hypothesis.
