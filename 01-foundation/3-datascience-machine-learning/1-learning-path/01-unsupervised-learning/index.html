    Example Scenario: Email Classification — Spam vs. Not Spam¶

    1. Supervised Learning¶

    In supervised learning, the algorithm is trained on labeled data.

    Scenario¶

    We have a dataset of past emails where each email is already labeled as "Spam" or "Not Spam".

    How it works¶

    1. Training Data:
    2. Email text → "You won a prize!" → Spam
    3. Email text → "Meeting at 10am" → Not Spam
    4. Email text → "Claim your free gift" → Spam
    5. Features extracted (word counts, sender address, links, etc.).
    6. The model learns patterns that distinguish spam from non-spam.
    7. For a new incoming email, the model predicts:
    8. "Spam" if it matches spam-like patterns.
    9. "Not Spam" otherwise.

    Real-Time Example¶

    • Gmail uses supervised learning with millions of labeled spam/not spam examples from user feedback.

    Python (Supervised — Logistic Regression Example)¶

    from sklearn.feature_extraction.text import CountVectorizer
from sklearn.linear_model import LogisticRegression

# Training Data
emails = [
    "You won a prize",
    "Meeting at 10am",
    "Claim your free gift",
    "Project deadline extended"
]
labels = [1, 0, 1, 0]  # 1 = Spam, 0 = Not Spam

# Feature Extraction
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(emails)

# Train Model
model = LogisticRegression()
model.fit(X, labels)

# Predict
test_email = ["Free tickets to the concert"]
print(model.predict(vectorizer.transform(test_email)))  # Output: [1] (Spam)

    ↩ Back to Top

    2. Unsupervised Learning¶

    In unsupervised learning, the algorithm works with unlabeled data.

    Scenario¶

    We have a large number of past emails but no spam/not spam labels.

    How it works¶

    1. The model groups emails into clusters based on content similarity.
    2. After clustering:
    3. Cluster A: "You won a prize", "Claim your free gift", "Free tickets" → Likely spam.
    4. Cluster B: "Meeting at 10am", "Project deadline extended" → Likely not spam.
    5. Labels are inferred later by human inspection or heuristics.

    Real-Time Example¶

    • Email filtering systems can first group unknown emails, then allow humans to label clusters, speeding up the training process.

    Python (Unsupervised — KMeans Example)¶

    from sklearn.feature_extraction.text import CountVectorizer
from sklearn.cluster import KMeans

# Unlabeled Emails
emails = [
    "You won a prize",
    "Meeting at 10am",
    "Claim your free gift",
    "Project deadline extended"
]

# Feature Extraction
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(emails)

# Apply KMeans
kmeans = KMeans(n_clusters=2, random_state=42)
kmeans.fit(X)

# Cluster Assignments
for email, label in zip(emails, kmeans.labels_):
    print(f"{email} → Cluster {label}")

    ↩ Back to Top

    ✅ Key Difference:
    - Supervised: Needs labeled data upfront.
    - Unsupervised: Finds patterns without labels.

    Supervised vs Unsupervised Learning — Example Scenarios¶

    This document presents various real-world examples of Supervised and Unsupervised learning problems, including their key components: features, labels, and the reasoning for classification.

    ↩ Back to Top

    1. Air Pollution Prediction¶

    Scenario:
    You measured the concentration of a certain type of air pollutant at different locations, under various weather conditions, times of day, and days of the week. Now you want to predict the air pollution concentration at a new location without additional measurements.

    Learning Type: Supervised Learning ✅

    Reasoning:
    - Features: Location, weather conditions, day, and time.
    - Label: Air pollution concentration (numerical).
    - This is a regression problem because the label is a continuous numeric value (e.g., 2000 particles/cm³ is less than 6000 particles/cm³).

    ↩ Back to Top

    2. Social Group Discovery in Offices¶

    Scenario:
    A researcher observed office workers over a month and recorded their interactions. The goal is to discover friendships or social groups.

    Learning Type: Unsupervised Learning ✅

    Reasoning:
    - Features: Records of interactions between people.
    - Labels: None (unknown social groups).
    - The goal is clustering people into groups based on interaction patterns.

    ↩ Back to Top

    3. Rocket Booster Lift Prediction (NASA)¶

    Scenario:
    NASA simulates rocket booster performance under various specifications. They want to predict simulated lift for new specifications without running full simulations.

    Learning Type: Supervised Learning ✅

    Reasoning:
    - Features: Rocket booster specifications.
    - Label: Simulated lift (numerical).
    - This is a regression task predicting a continuous variable.

    ↩ Back to Top

    4. Bird Video Compression¶

    Scenario:
    A small bird-monitoring camera captures video, but bandwidth is limited. The goal is to compress video before transmission.

    Learning Type: Unsupervised Learning ✅

    Reasoning:
    - Features: Pixel values over time.
    - Labels: None.
    - Uses clustering (e.g., grouping similar pixels in color and time) for compression.

    ↩ Back to Top

    5. Student Algorithm Error Analysis¶

    Scenario:
    In an online course, students implement an algorithm for an exercise. You want to understand the different types of errors to improve teaching.

    Learning Type: Unsupervised Learning ✅

    Reasoning:
    - Features: Student solutions and code errors.
    - Labels: None (no predefined error categories).
    - Goal is to find patterns in mistakes, possibly for adaptive learning.

    ↩ Back to Top

    6. Email Classification (Spam or Not Spam)¶

    Scenario:
    A dataset of emails, each labeled as spam or not spam. You want to predict whether a new email is spam.

    Learning Type: Supervised Learning ✅

    Reasoning:
    - Features: Words/phrases, metadata, and structure of the email.
    - Label: Spam or Not Spam (categorical).
    - This is a classification problem because the label is discrete with no inherent order.

    What is Clustering?¶

    Clustering is an unsupervised learning task that groups data points into clusters so that points in the same cluster are similar to each other and dissimilar to points in other clusters. Unlike classification, clustering operates without labels, discovering structure directly from the data.

    • Goal: assign each data point to exactly one group (hard clustering) or to groups with probabilities (soft clustering).
    • Outcome: descriptive structure that can reveal segments, communities, or latent themes.

    Back to Top

    Example: Archaeology Dig¶

    Imagine an archaeology site where each artifact’s location is recorded as (east, north) coordinates relative to a marker. Historians suspect three families lived at the site. By clustering the artifact locations, we may recover three spatial groups that correspond to where those families lived and discarded objects.

    Visual (inline SVG sketch)¶

    Back to Top

    Similarity & Distance¶

    Clustering depends on a similarity notion. Common choices use a distance metric \( d(\cdot,\cdot) \) over feature vectors \(\mathbf{x} \in \mathbb{R}^d\).

    • Euclidean: \( d(\mathbf{x},\mathbf{y}) = \lVert \mathbf{x} - \mathbf{y} \rVert_2 \)
    • Manhattan: \( d(\mathbf{x},\mathbf{y}) = \lVert \mathbf{x} - \mathbf{y} \rVert_1 \)
    • Cosine distance: \( d(\mathbf{x},\mathbf{y}) = 1 - \frac{\mathbf{x}\cdot\mathbf{y}}{\lVert\mathbf{x}\rVert\,\lVert\mathbf{y}\rVert} \)

    Choose a distance aligned with the data geometry (e.g., cosine for text embeddings).

    Back to Top

    Clustering vs. Classification¶

    • Classification (supervised): learn a mapping from features to known labels (e.g., family names).
    • Clustering (unsupervised): discover groups with no labels available; the structure is inferred from the data alone.

    Back to Top

    Common Algorithms¶

    🔵 K-means (hard, centroid-based)¶

    Minimizes within-cluster variance (sum of squared distances to cluster centroids). Objective:

    The K-means objective:

    \[ \min_{\{C_k\}_{k=1}^K} \sum_{k=1}^{K} \sum_{\mathbf{x}\in C_k} \bigl\| \mathbf{x}-\boldsymbol{\mu}_k \bigr\|_2^2 \]
    • Fast and scalable; assumes roughly spherical clusters of similar size.
    • Sensitive to initialization and outliers.

    🟢 Hierarchical clustering (agglomerative/divisive)¶

    • Builds a tree (dendrogram) of nested clusters using a linkage: single, complete, average, Ward’s.
    • No need to pre-specify \(K\); choose a cut level on the dendrogram.

    🟠 DBSCAN (density-based)¶

    • Finds clusters as regions of high density separated by low-density regions.
    • Parameters: \(\varepsilon\) (neighborhood radius) and minPts.
    • Detects arbitrary shapes and flags noise; struggles with varying densities.

    🟣 Gaussian Mixture Models (soft clustering)¶

    • Probabilistic model: data from a mixture of Gaussians; assigns soft responsibilities.
    • Learned via EM algorithm; captures elliptical clusters with covariance structure.

    Back to Top

    Choosing the Number of Clusters¶

    • Elbow method: inspect the curve of within-cluster sum of squares vs. \(K\) and look for an “elbow.”
    • Silhouette analysis: prefer \(K\) that maximizes average silhouette score.
    • Domain constraints: business or scientific context may dictate plausible \(K\).

    Back to Top

    Evaluating Cluster Quality¶

    Given a point \(i\), let \(a(i)\) be the mean distance to points in its own cluster, and \(b(i)\) the smallest mean distance to points in another cluster. The silhouette is:

    \[ s(i) = \frac{b(i) - a(i)}{\max\{a(i), b(i)\}} \in [-1, 1]. \]

    • Average \(s(i)\) close to 1 ⇒ well-separated clusters; near 0 ⇒ overlapping; negative ⇒ misassigned.

    Other diagnostics: Calinski–Harabasz, Davies–Bouldin, stability under resampling.

    Back to Top

    Challenges & Pitfalls¶

    • Scale sensitivity: standardize features; otherwise one feature may dominate distance.
    • Non-spherical structure: K-means may fail on elongated or manifold-shaped clusters.
    • Outliers & noise: can skew centroids; use robust methods (DBSCAN, trimming).
    • High dimensionality: distance concentration; consider PCA or UMAP first.
    • Initialization: multiple restarts (K-means++), consensus clustering for robustness.

    Back to Top

    Minimal Python Example¶

    # Minimal clustering demo: K-means and DBSCAN on 2D data
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans, DBSCAN
from sklearn.metrics import silhouette_score

# synthetic data
X, y_true = make_blobs(n_samples=600, centers=3, cluster_std=0.75, random_state=42)

# K-means
kmeans = KMeans(n_clusters=3, n_init="auto", random_state=42)
labels_km = kmeans.fit_predict(X)
sil_km = silhouette_score(X, labels_km)

# DBSCAN (tune eps/min_samples for data scale)
db = DBSCAN(eps=0.8, min_samples=5)
labels_db = db.fit_predict(X)
mask = labels_db != -1  # ignore noise for silhouette if needed
sil_db = silhouette_score(X[mask], labels_db[mask]) if mask.any() else float("nan")

print(f"K-means silhouette: {sil_km:.3f}")
print(f"DBSCAN silhouette (excl. noise): {sil_db:.3f}")

    Overview¶

    K-Means Clustering¶

    K-Means Clustering is one of the most popular algorithms in Unsupervised Learning.

    Why K-Means is popular: - Fast runtime: Simple steps and quick computations. - Parallelizable: Can utilize multiple CPU cores or processors. - Easy to implement: Straightforward to understand and code, with minimal parameter tuning.

    Assumptions¶

    • Known K value: The number of clusters \( K \) is specified in advance.
    • Continuous features: Each data point can be represented as a vector of continuous values.

    Example:
    In an archaeology survey, the location of an artifact might be expressed as:

    \[ \mathbf{x} = [\text{east\_distance\_m}, \ \text{north\_distance\_m}] \]

    For example, point \(X_3\) can be represented as:

    \[ X_3 = [1.5, \ 4.2] \]

    Dissimilarity & Distance¶

    Euclidean Distance¶

    For two points \((X_1, Y_1)\) and \((X_2, Y_2)\):

    \[ d = \sqrt{(X_2 - X_1)^2 + (Y_2 - Y_1)^2} \]

    Squared Euclidean Distance¶

    For vectors \(\mathbf{X} = (x_1, x_2, \dots, x_n)\) and \(\mathbf{Y} = (y_1, y_2, \dots, y_n)\):

    \[ d^{2} = \sum_{i=1}^{n} (x_i - y_i)^{2} \]

    In K-Means, using Squared Euclidean Distance produces the same clustering result as Euclidean distance but is computationally more convenient.

    ↩ Back to Top

    Output of K-Means¶

    • Cluster Assignments: Each data point belongs to exactly one cluster.
    • Cluster Centers: For each cluster \(k\), we find a centroid \(\mu_k\).

    Example:
    If \(S_3\) is the set of data points assigned to the cluster with center \(\mu_3\), then:

    \[ S_3 = \{\, \mathbf{x} \mid \mathbf{x} \ \text{is closest to} \ \mu_3 \,\} \]

    ↩ Back to Top

    Points to Note¶

    • K-Means assumes continuous numeric features — categorical “Yes/No” data is not ideal.
    • Requires exact K value beforehand (which is not always known).
    • Not suited for purely binary vectors unless transformed appropriately.

    The K-Means Algorithm¶

    Quick Links¶

    • Euclidean Distance
    • Squared Euclidean Distance
    • Output of K-Means

    ↩ Back to Top | ⇧ Go to Top of This Topic

    K-Means is a subset of general clustering problems in which: - Each data point is represented as a vector of continuous values. - Squared Euclidean Distance is used as the dissimilarity measure.

    ↩ Back to Top

    Objective¶

    The output of K-Means consists of:

    • A set of cluster centers: \( \mu_1, \mu_2, \dots, \mu_k \)
    • A set of assignments of data points to clusters:

    \[ S_k = { \mathbf{x} \ | \ \mathbf{x} \ \text{is closest to} \ \mu_k } \]

    The main goal: Minimize the Global Dissimilarity within clusters.

    ↩ Back to Top

    Global Dissimilarity¶

    • Dissimilarity within a cluster = Sum of squared distances from each point to its cluster center:

    \[ \text{ClusterDissimilarity}(S_k) = \sum_{\mathbf{x} \in S_k} | \mathbf{x} - \mu_k |^2 \]

    • Global Dissimilarity = Sum over all clusters:

    \[ \text{GlobalDissimilarity} = \sum_{k=1}^{K} \sum_{\mathbf{x} \in S_k} | \mathbf{x} - \mu_k |^2 \]

    • Objective Function: Minimize this global dissimilarity.

    ↩ Back to Top

    The K-Means Algorithm (Lloyd’s Algorithm)¶

    Steps:

    1. Initialize cluster centers
    2. Randomly pick \( K \) points from data (Random Initialization)

    3. Or use K-Means++ for better spread.

    4. Repeat until convergence:

    5. Assignment step: Assign each point to the cluster with the closest center:

      \[ \text{Assign}(\mathbf{x}) = \underset{k}{\mathrm{argmin}} \ | \mathbf{x} - \mu_k | \]

    6. Update step: Recalculate each cluster center as the mean of assigned points:

      \[ \mu_k = \frac{1}{|S_k|} \sum_{\mathbf{x} \in S_k} \mathbf{x} \]

    ↩ Back to Top

    Notes on Efficiency¶

    • Distance computation for each data point is independent → supports Embarrassingly Parallel Computation.
    • Algorithm always converges in finite time (though not necessarily to the global optimum).

    ↩ Back to Top

    Key Considerations¶

    • K must be known in advance (or determined with methods like the Elbow Method).
    • Works best with continuous numerical features.
    • Sensitive to initialization — K-Means++ helps.

    Evaluation in Supervised vs. Unsupervised Learning¶

    In supervised learning (classification): - We have labeled data. - We split data into training data (with labels) and test data (with labels set aside for evaluation). - The evaluation is straightforward:
    Predict labels for the test data, compare with true labels, and compute the percentage of correct predictions.

    In clustering (unsupervised): - We typically do not have labels. - If we do have access to a ground truth clustering (e.g., in archaeology or manually clustered images), we can compare results. - However, label permutations don’t affect correctness — what matters is whether pairs of points are in the same or different clusters in both our algorithm and the ground truth.

    External Evaluation Measures¶

    When ground truth is available, we can use metrics like: - Rand Index
    - Adjusted Rand Index

    These work by counting: - Pairs of data points that are in the same cluster in both algorithm and ground truth. - Pairs that are in different clusters in both.

    Then they normalize the result for comparison.

    Challenges¶

    • Rarely do we have ground truth in real clustering tasks.
    • Objective function values (like K-Means’ within-cluster sum of squares) let us compare different runs but do not tell us if the clustering is objectively “good.”
    • Evaluation may fail to capture the exact patterns we are looking for.

    Heuristic Approaches¶

    1. Visualization¶

    • Plot the clustering results and visually inspect patterns.
    • Examples:
    • Archaeology clusters (clear groupings by location).
    • Image segmentation (distinguish objects).
    • Topic modeling (group related words and check coherence).

    2. High-Dimensional Visualization Tools¶

    • GGOBI: Useful for finding meaningful 2D projections of high-dimensional datasets.
    • Helpful when the dataset has many features (e.g., health metrics) and is not easily plottable.

    3. Crowdsourced Evaluation¶

    • Use platforms like Amazon Mechanical Turk to get human feedback on cluster quality.
    • Can be expensive in time and money.

    Internal Evaluation Measures¶

    Do not require ground truth.
    Goal: Ensure points in the same cluster are close together, and points in different clusters are far apart.

    Examples: - Silhouette Coefficient: Measures how similar a point is to its own cluster compared to other clusters. - Split-sample validation: Split the dataset, cluster each half, and compare the resulting cluster assignments.

    Summary¶

    • External Evaluation: Needs ground truth (e.g., Rand Index, Adjusted Rand Index).
    • Internal Evaluation: No ground truth needed (e.g., Silhouette Coefficient).
    • Visualization & Tools: Help qualitative assessment.
    • Crowdsourcing: Adds human judgment at a cost.

    Ground Truth Information in Clustering¶

    Definition¶

    In clustering, ground truth information refers to the true, known class labels or actual group memberships of data points.
    It is the reference standard used to evaluate how well a clustering algorithm performs.

    ↩ Back to Top

    Why It Matters¶

    When we perform clustering, the algorithm groups data based on similarity or distance measures without using labels.
    However, if we already have the true labels (ground truth), we can compare them to the predicted clusters to measure accuracy.

    When Ground Truth is Available¶

    • Synthetic datasets: When we generate data with known cluster assignments.
    • Benchmark datasets: Public datasets like Iris, MNIST, or CIFAR-10 have known labels.
    • Pre-labeled business data: E.g., customer segments determined by domain experts.

    ↩ Back to Top

    Evaluation Metrics Using Ground Truth¶

    When ground truth labels are available, clustering performance can be evaluated using external evaluation metrics, such as:

    1. Rand Index (RI)
      Measures the percentage of correct decisions made by the clustering algorithm.
    2. Adjusted Rand Index (ARI)
      Corrects RI for chance grouping.
    3. Normalized Mutual Information (NMI)
      Measures the similarity between predicted clusters and ground truth labels based on information theory.
    4. Fowlkes–Mallows Index (FMI)
      Measures the geometric mean of precision and recall for clustering.
    5. Purity
      Measures the extent to which clusters contain only members of a single class.

    When Ground Truth is NOT Available¶

    If ground truth is unknown, we must rely on internal evaluation metrics (e.g., Silhouette Score, Davies–Bouldin Index) that do not require labels.

    ↩ Back to Top

    Example¶

    Scenario:
    We have data about animals described by physical traits (weight, number of legs, type of covering).
    - Ground Truth: Actual species name (Dog, Cat, Bird, etc.).
    - Predicted Clusters: Grouping from K-Means algorithm.

    Evaluation:
    We can calculate ARI or NMI to see how close the K-Means clusters match the true species categories.

    Overview¶

    We already know about the clustering problem and the particular algorithm for coming up with the solution — K-Means (also known as Lloyd’s Algorithm).

    Now the question is:
    What happens if the output of the K-Means algorithm is not what we expected or wanted?

    This section discusses: - Troubleshooting K-Means - Ways to make K-Means clustering better

    ↩ Go to Top of This Topic | ↩ Back to Global Top

    Ensuring Best Output¶

    • Finite possibilities: K-Means eventually stops because there are only a finite number of possible clusterings.
    • Progress condition: The algorithm moves to a new clustering only if it decreases the K-Means objective function.
    • Not always quick: Although K-Means is generally fast, on some datasets it may take longer.

    ↩ Go to Top of This Topic | ↩ Back to Global Top

    Speed-Up Techniques¶

    In K-Means, we normally compute the distance from every data point to every cluster center.

    However, Triangle Inequality can help avoid checking every center.

    Idea:
    If a data point is clearly closer to one cluster center, far-away centers can be skipped in comparisons — improving efficiency.

    ↩ Go to Top of This Topic | ↩ Back to Global Top

    Local vs Global Optimum¶

    • Local Optimum: The point where K-Means stops might not be the minimum possible value of the objective function.
    • Global Optimum: The true minimum global dissimilarity — hard to guarantee in practice.

    ↩ Go to Top of This Topic | ↩ Back to Global Top

    Strategies to Improve Results¶

    1. Multiple Random Initializations¶

    Run K-Means multiple times with different random starting points, then select the result with the lowest global dissimilarity. - Can be parallelized to reduce runtime impact.

    2. Smarter Initialization — K-Means++¶

    Improves centroid initialization by: - Starting with one random centroid. - Selecting subsequent centroids with probability proportional to the squared distance from the nearest existing centroid. - Ensures centroids are well spread apart. - Often improves both accuracy and runtime.

    ↩ Go to Top of This Topic | ↩ Back to Global Top

    Final Note¶

    Even if we somehow reached the global optimum, we might still be dissatisfied with the results.

    In that case, the problem might not be with the algorithm but with the clustering problem definition itself — a topic for later discussion.

    Overview¶

    K-Means clustering is powerful, but it isn’t ideal for every dataset. It assumes Euclidean distance, spherical clusters, and similar cluster sizes. Sometimes we need different similarity notions.

    ↩ Back to This Topic’s Top · ↩ Back to Top

    Limitations of K-Means Similarity¶

    Clusters of Unequal Size¶

    • Issue: Large vs small clusters can be split incorrectly by K-Means.
    • Remedy: Use Gaussian Mixture Models (GMMs) with different covariances (fit via EM) to model unequal-sized/elliptical clusters.

    ↩ Back to This Topic’s Top · ↩ Back to Top

    Sensitivity to Outliers¶

    • Issue: Euclidean distance is sensitive to extreme points, causing spurious clusters.
    • Remedy: Prefer robust distances or K-Medoids; consider trimming/outlier handling.

    ↩ Back to This Topic’s Top · ↩ Back to Top

    Alternative Distance Measures¶

    \(L_2\) (Euclidean)¶

    \[ d_{L2}(\mathbf{x}, \mathbf{y}) = \sqrt{\sum_{i=1}^{n} (x_i - y_i)^2} \]

    \(L_1\) (Manhattan)¶

    \[ d_{L1}(\mathbf{x}, \mathbf{y}) = \sum_{i=1}^{n} \lvert x_i - y_i \rvert \]
    • With \(L_1\), a K-Means–like procedure becomes K-Medoids (centers are medoids; in 1D the medoid is the median).

    ↩ Back to This Topic’s Top · ↩ Back to Top

    Clusters of Different Shapes¶

    For non-convex or nested patterns, try: - Radial similarity or polar transforms - Kernel methods - Agglomerative (hierarchical) clustering

    ↩ Back to This Topic’s Top · ↩ Back to Top

    Non-Numerical Features¶

    K-Means expects continuous numeric features. For text/binary/categorical: - Redefine similarity (e.g., Jaccard, Hamming), or - Transform to numeric space first (embeddings, one-hot/target encodings) before clustering.

    We have discussed different ways of troubleshooting the K-Means algorithm.

    Now we will take a closer look at our data. In the archaeology example we discussed earlier, our dataset represented the locations of archaeological artifacts. For each data point, we recorded: - Distance east from a reference marker. - Distance north from the same marker.

    However, datasets can take many other forms. Before running K-Means, we should ask the following questions:

    1. Is Our Data Featurized?¶

    Example: Suppose we have made a fitness app and collected data about our users such as: - Age
    - Height
    - Education
    - Post frequency on the app forum

    K-Means requires a vector representation. Each entry in the vector is a feature with a particular meaning.

    We can represent the dataset as a matrix where each row is a user, and each column is a feature.

    2. Are Features Continuous Numbers?¶

    K-Means requires continuous-valued features.
    In the example: - Age: Already continuous (years).
    - Height: Convert to inches.
    - Education: Convert to years (e.g., 16 for a Bachelor's Degree).
    - Smoothie quantity: Keep as is.

    3. Are Features Commensurate?¶

    K-Means assumes spherical clusters (same width in all directions).
    If feature scales differ greatly (e.g., \(x \in [0,1]\), \(y \in [0,10]\)), the algorithm may produce skewed clusters.

    Solution:
    - Normalization: Scale each feature to \([-1,1]\).
    - Standardization: Scale each feature to have a standard deviation of 1.

    4. Are There Too Many Features?¶

    Some features may be irrelevant or redundant.
    - If identified via domain knowledge, remove them beforehand.
    - Otherwise, use dimensionality reduction algorithms such as Principal Component Analysis (PCA).

    Example:
    Recording a one-dimensional motion (spring and ball) with 5 cameras gives 4 redundant features.
    PCA extracts the most relevant feature.

    5. Can We Use Domain Knowledge?¶

    • Remove unhelpful features before PCA or K-Means.
    • Transform features to better fit K-Means assumptions if necessary.
    • Use domain-specific knowledge to improve results.

    Assumptions of K-Means Clustering - Part 1¶

    We already examined some of the assumptions in K-Means clustering and discussed what to do if we want to cluster the data but our application or data do not quite fit those assumptions.

    K-Means Clustering is just one particular type of fixed \( K \) clustering — meaning the value of \( K \) is fixed. Here we also assume the number of clusters is finite.
    Even if we don’t know the number of clusters in advance, we often still assume that the number of clusters in our data is some fixed and finite number.

    ↩ Back to Top
    ↩ Go to Assumptions of K-Means Clustering

    When This Assumption Fails¶

    This assumption might not always be correct. In big data scenarios, our dataset might not be static — we could have Streaming Data where new data is continuously added.

    Example:
    - Wikipedia Phenomenon:
    - English Wikipedia alone averages around 800 new articles/day.
    - Even if we have read many articles before, new topics are constantly emerging.
    - Suppose we have 100 Wikipedia articles — we could cluster them into topics.
    - With thousands or millions of articles, new topics keep appearing over time.

    ↩ Back to Top
    ↩ Go to Assumptions of K-Means Clustering

    Growing Number of Clusters with Data Size¶

    As datasets grow, the number of clusters may also grow. This means the complexity of our model should be able to scale with dataset size.

    Examples: 1. Biological discovery:
    - Humans have discovered species for centuries, yet every week new species are found.
    - New clusters (species categories) appear as more data (observations) are collected.

    1. Fitness app data:

    2. Asking users about exercise routines will keep revealing new and unusual exercises, even after surveying thousands of people.

    3. Genetics and health:

    4. Studying more individuals’ DNA might reveal new, previously unknown ancestral populations.

    5. Observing more newborns could uncover new and unique health issues, prompting new treatment approaches.

    6. Social networks:

    7. As more people join, new friend groups and interests emerge over time.

    Moving Beyond Fixed \( K \)¶

    In all these scenarios, we do not want a fixed \( K \) for clustering.
    Instead, we want \( K \) to grow with the size of the data.

    One solution is Non-Parametric Bayesian Methods: - Non-Parametric here means allowing many (potentially infinite) parameters. - The number of parameters grows as the dataset grows. - More complex than K-Means, but can adapt to dynamic datasets.

    Recent advancement:
    - MAD-BAYES — Converts Non-Parametric Bayesian approaches into K-Means-like problems for clustering and other Unsupervised Learning tasks.

    Assumptions of K-Means Clustering - Part 2¶

    In the last article, we discussed the case where we cannot assume a fixed number of clusters and where model complexity should grow with the size of the dataset.

    In this article, we address cases where clustering does not adequately represent the hidden patterns we want to uncover in the data.

    When Clustering Fails to Capture Patterns¶

    Example:
    - Suppose we have a website where people post pictures of their pets.
    - Ideally, we want a clustering algorithm to group: - All cat images into one cluster - All dog images into another - All lizard images into another

    We could represent this clustering in a table/matrix: - Each row = one image - Each column = a cluster - A "1" in the corresponding column marks the image’s assigned cluster

    Problem:
    - If someone posts a picture containing both a cat and a dog, which cluster does it belong to?
    - What if an image contains no animals?

    K-Means forces each data point to belong to exactly one cluster. There may be uncertainty in assignment, but the underlying assumption is that there is one true group for each data point.

    ↩ Back to Top
    ↩ Go to Assumptions of K-Means Clustering

    Feature Allocation and Mixed Membership¶

    In some cases, data points: - May belong to multiple groups simultaneously - May belong to no groups - May belong to only one group

    Here, we call the groups features (different from earlier feature definitions) and the structure is a Feature Allocation instead of clustering.

    Mixed Membership:
    - Data points can belong to multiple groups at once.
    - Clustering (or Mixture Models) assumes one group per data point.
    - Admixture Models allow multiple memberships per data point.

    These terms — Feature Allocation, Mixed Membership, Admixture — all describe cases where items can belong to multiple groups.

    ↩ Back to Top
    ↩ Go to Assumptions of K-Means Clustering

    Applications of Mixed Membership Models¶

    Text Analysis Example:
    - Analyzing New York Times archives may yield topics like sports, arts, and economics.
    - A movie review of Moneyball: - Arts → because it’s a movie review - Sports → because it’s about baseball - Economics → because it involves analytics/statistics in player trades

    Genomics Example:
    - DNA may contain parts from multiple ancestral groups.

    Social Networks Example:
