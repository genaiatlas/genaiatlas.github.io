    Matrix and Vectors¶

    To understand machine learning in-depth, let us first understand a few topics related to linear algebra. You do not necessarily need to understand linear algebra in-depth, to get started with machine learning. However, it will be useful in understanding the mathematics behind machine learning algorithms.

    In linear algebra, data is mostly represented using matrices and vectors.

    Matrix¶

    Matrices (plural of matrix) are used throughout machine learning algorithms, specifically for input variables, i.e., the variables we try to understand in machine learning. A matrix of size LaTeX: m\times n is a two-dimensional array that has m rows and n columns.

    Vector¶

    A vector is a one-dimensional array that has only one row - called a row vector, or just one column, also called a column vector.

    For example, in the below figure, X is a matrix with 3 rows and 2 columns, while Y is a simple column vector.

    Key Equations (MathJax)¶

    • Projection of a vector \( \mathbf{x} \) onto unit vector \( \mathbf{u} \): \[ \mathrm{proj}_{\mathbf{u}}(\mathbf{x}) \;=\; (\mathbf{x}!\cdot!\mathbf{u})\,\mathbf{u} \]

    • Least‑squares solution (full column rank):
      \[ \hat{\mathbf{w}} \;=\; (X^\top X)^{-1}X^\top \mathbf{y} \]

    Visual (inline SVG – projection)¶

    Real‑Time Use Case¶

    Latency‑sensitive vector search: Project high‑dimensional query embeddings onto a smaller subspace (e.g., PCs) to reduce ANN query time while retaining most energy.

    Python Snippet¶

    import numpy as np

# Query and basis (orthonormal columns)
x = np.random.randn(768)
U = np.linalg.qr(np.random.randn(768, 64))[0]   # 64-dim subspace
proj = U @ (U.T @ x)     # projection
residual = x - proj
energy_kept = np.linalg.norm(proj)**2 / np.linalg.norm(x)**2
print(f"Energy kept: {energy_kept:.3f}")

    Eigenvectors & Eigenvalues¶

    Eigenvectors keep their direction under a linear map \(A\): \( A\mathbf{v}=\lambda\mathbf{v} \). Non‑trivial solutions exist where \( \det(A-\lambda I)=0 \).

    Visual (shear eigenvector intuition)¶

    Real‑Time Use Case¶

    RNN stability & spectral norm: Ensure the largest \(|\lambda|\) of the recurrent matrix is \(<1\) to prevent exploding activations. Also used for spectral clustering and PageRank (dominant eigenvector).

    Python Snippet¶

    import numpy as np

A = np.array([[0.9, 0.2],
              [0.1, 0.8]])
eigvals, eigvecs = np.linalg.eig(A)
spectral_radius = np.max(np.abs(eigvals))
print("Eigenvalues:", eigvals)
print("Spectral radius:", spectral_radius)

    Why are Eigenvectors important?¶

    The directional invariance of Eigenvectors turns out to be an incredibly important mathematical property, and is utilized by many applications - Principal Component Analysis (PCA), for example, is a highly popular data projection technique that can be used to reduce the dimensionality of a dataset and visualize it in lower dimensions.

    Covariance¶

    Variance:¶

    Variance helps us understand how far our random variable is spread out from the mean, for example, the income of the people may have a high variance as some people may have high income levels.

    Covariance¶

    Covariance measures joint variability.

    It measures how much two random variables vary together. e.g. The income of a person and the expenses of that person in a population. More precisely, covariance refers to the measure of how two random variables in a data set will change together. A positive covariance means that the two variables at hand are positively related, and they move in the same direction. A negative covariance means that the variables are inversely related, or that they move in opposite directions.

    For data matrix \(X\in\mathbb{R}^{n\times d}\) (rows = samples), the unbiased covariance is: \[ \Sigma \;=\; \frac{1}{n-1}(X-\bar{X})^\top(X-\bar{X}) \]

    Visual (scatter & ellipse)¶

    Real‑Time Use Case¶

    Drift monitoring: Recompute feature covariance online and compare with a baseline to detect distribution shift in production.

    Python Snippet¶

    import numpy as np

X_ref = np.random.randn(10_000, 16)            # baseline
X_now = np.random.randn(10_000, 16) + 0.2      # shifted

def cov(x):
    x = x - x.mean(0, keepdims=True)
    return (x.T @ x) / (x.shape[0]-1)

Sigma_ref = cov(X_ref)
Sigma_now = cov(X_now)

fro_diff = np.linalg.norm(Sigma_ref - Sigma_now, 'fro')
print("Frobenius difference:", fro_diff)

    Kullback-Leibler KL Divergence¶

    For continuous densities \(p,q\): \(D_{\mathrm{KL}}(p\parallel q)=\int p(x)\log\frac{p(x)}{q(x)}dx\).
    For Gaussians \(\mathcal{N}(\mu,\Sigma)\) and \(\mathcal{N}(\mu_0,\Sigma_0)\): \[ D_{\mathrm{KL}} = \tfrac{1}{2}!\left(\mathrm{tr}(\Sigma_0^{-1}\Sigma) + (\mu_0-\mu)^\top\Sigma_0^{-1}(\mu_0-\mu) - k + \ln\frac{\det\Sigma_0}{\det\Sigma}\right) \]

    Visual¶

    Real‑Time Use Case¶

    Anomaly scoring in streams: Fit \(q\) to recent data; score new batches with \(D_{\mathrm{KL}}(p\parallel q)\) using a reference \(p\).

    Python Snippet¶

    import numpy as np

mu_p = np.zeros(8);  Sigma_p = np.eye(8)
mu_q = np.ones(8)*0.3;  Sigma_q = np.eye(8)*1.2

def kl_gaussians(mu, Sigma, mu0, Sigma0):
    k = mu.shape[0]
    iS0 = np.linalg.inv(Sigma0)
    term1 = np.trace(iS0 @ Sigma)
    term2 = (mu0 - mu).T @ iS0 @ (mu0 - mu)
    term3 = -k
    term4 = np.log(np.linalg.det(Sigma0)/np.linalg.det(Sigma))
    return 0.5*(term1 + term2 + term3 + term4)

print("KL(p||q) ≈", kl_gaussians(mu_p, Sigma_p, mu_q, Sigma_q))

    The intuition behind the KL divergence score:¶

    When the probability for an event from p is large, but the probability for the same event in q is small, there is a large divergence. When the probability from p is small and the probability from q is large, there is also a large divergence, but not as large as in the former case.

    Unsupervised Learning¶

    Discover structure without labels: clustering, density estimation, dimensionality reduction, topic modeling, etc.

    Data science and machine learning algorithmic techniques can be divided into three categories:

    • Supervised Learning: The algorithm has prior data (labeled data) to learn from.
    • Unsupervised Learning: The algorithm has no prior labeled data to learn from — it learns from unlabeled data by finding patterns among examples and grouping them accordingly.
    • Reinforcement Learning: The algorithm learns patterns or behaviors recursively by taking actions to maximize a certain reward, and uses feedback from the environment to learn the best action to take under the right circumstances.

    What is Unsupervised Learning?¶

    Unsupervised Learning is a category of techniques that train computers to use a set of unlabeled / unseen data and learn by themselves.
    The algorithm is provided with a large volume of data and expected to identify hidden patterns.

    • Since there's no prior label available for each data instance, there is no defined correct outcome.
    • The machine’s task is to determine whether there are patterns in the given data.

    Key Use Cases¶

    Clustering¶

    Clustering divides data into groups such that:

    • Each group shares similar properties internally
    • Each group is dissimilar to other groups

    Example: Customer Segmentation¶

    A company launching a new product wants to segment customers to target the right audience. Possible segmentation criteria:

    1. Demographics: Occupation, age, gender
    2. Income & Spending Habits
    3. Geographic Location

    This is unsupervised learning because:

    • There was no labeled information about customers
    • Features such as age, gender, income were used
    • The algorithm grouped similar individuals together without knowing the meaning of each group

    Association¶

    Association learning is a rule-based machine learning and data mining technique.

    • Finds important relationships between variables or features in a dataset
    • Checks for dependency of one data item on another
    • Often used to increase profitability via cross-selling or recommendations

    Example:
    If customers who buy bread often also buy butter, the store can place these items together to increase sales.

    Visual (concept map)¶

    Real‑Time Use Case¶

    User segmentation: Cluster users nightly to personalize recommendations and pricing.

    Python Snippet¶

    import numpy as np
from sklearn.cluster import KMeans

X = np.random.randn(50_000, 16)  # features
kmeans = KMeans(n_clusters=8, n_init='auto', random_state=0).fit(X)
labels = kmeans.labels_
print("Cluster sizes:", np.bincount(labels))

    Dimensionality Reduction (PCA & t‑SNE)¶

    Dimensionality Reduction¶

    Dimensionality reduction is the transformation of data from a high-dimensional space into a low-dimensional space such that:

    • The low-dimensional representation retains meaningful properties of the original data
    • The structure is close to its intrinsic dimension

    Common methods:

    • PCA (Principal Component Analysis)
    • t-SNE (t-distributed Stochastic Neighbor Embedding)

    • UMAP (Uniform Manifold Approximation and Projection)

    • PCA: projects onto directions of maximal variance (eigenvectors of covariance).

    The main idea of principal component analysis (PCA) is to reduce the dimensionality of a dataset consisting of many variables correlated with each other, either heavily or lightly, while retaining the variation present in the dataset.

    This is done by transforming the variables to a new coordinate space of variables, which are known as principal components (or simply, the PCs), and are orthogonal to each other.

    The selection of principal components is such that the retention of variation present in the original variables is the maximum for the first principal component and decreases as we move down in order. The principal components are the eigenvectors of the covariance matrix, and hence they are orthogonal.

    \[ X \approx ZW^\top,\quad W = \text{top-}k\ \text{eigenvectors of } \Sigma \]

    Visual (principal axes)¶

    Real‑Time Use Case¶

    Telemetry compression: Stream PCA to keep top‑k components for downstream anomaly detection and faster query.

    Python Snippet - Two Dimensions¶

    import numpy as np
from sklearn.decomposition import PCA

X = np.random.randn(10000, 256)
pca = PCA(n_components=32, svd_solver='randomized', random_state=0).fit(X)
Z = pca.transform(X)
print("Explained variance ratio sum:", pca.explained_variance_ratio_.sum())

    Python Snippet - Three Dimensions¶

    import numpy as np
np.random.seed(1)

vec1 = np.array([0, 0, 0])
mat1 = np.array([[1, 0, 0], [0, 1, 0], [0, 0, 1]])
sample_for_class1 = np.random.multivariate_normal(vec1, mat1, 20).T
assert sample_for_class1.shape == (3, 20), "The dimension of the sample_for_class1 matrix is not 3x20"

vec2 = np.array([1, 1, 1])
mat2 = np.array([[1, 0, 0], [0, 1, 0], [0, 0, 1]])
sample_for_class2 = np.random.multivariate_normal(vec2, mat2, 20).T
assert sample_for_class2.shape == (3, 20), "The dimension of the sample_for_class2 matrix is not 3x20"

all_data = np.concatenate((sample_for_class1, sample_for_class2), axis=1)
assert all_data.shape == (3, 40), "The dimension of the all_data matrix is not 3x20"
    • t‑SNE/UMAP: preserve local neighborhood structure for visualization.

    The t-SNE algorithm calculates a similarity measure between pairs of instances in the high dimensional space and in the low dimensional space. This is done by setting the probabilities from the low-dimensional space similar to those of the high-dimensional space. We measure the difference between the probability distributions of the two-dimensional spaces using Kullback-Leibler divergence and try to optimize it.

    Distance & Scaling Measures¶

    Unsupervised learning algorithms use different distance measures or similarity/dissimilarity measures between each pair of observations to group data into different clusters. Points which are close to each other on that distance metric are likely to be grouped into the same cluster, while points far apart on that distance metric are likely to be members of different clusters. All this is done by computing a distance matrix that has distances between every pair of observations. There are different ways of calculating these distances, some of which are mentioned below:

    Euclidean distance: Euclidean distance is calculated as the square root of the sum of the squared differences between two vectors.

    • L1 (Manhattan): \( |\mathbf{x}|_1 = \sum_i |x_i| \)
    • L2 (Euclidean): \( |\mathbf{x}|_2 = \sqrt{\sum_i x_i^2} \)
    • Cosine distance: \( 1 - \frac{\mathbf{x}\cdot\mathbf{y}}{|\mathbf{x}|_2|\mathbf{y}|_2} \)

    Visual (unit balls)¶

    Real‑Time Use Case¶

    Vector search: Use cosine similarity for text/image embeddings; standardize vectors to unit norm for stable nearest‑neighbor ranking.

    Python Snippet¶

    import numpy as np

X = np.random.randn(1000, 768)
X = X / np.linalg.norm(X, axis=1, keepdims=True)  # unit-norm
q = np.random.randn(768); q /= np.linalg.norm(q)
scores = X @ q
ix = np.argsort(-scores)[:5]
print("Top-5 indices:", ix)

    Scaling¶

    Why Scaling is Important¶

    Input variables in a dataset may have different units (e.g., kilometers, hours, kilograms), resulting in different scales.
    Without scaling: - 1 km would be treated the same as 1 kg or 1 hour. - Features with larger numeric ranges may dominate the model’s decision-making. - Models become unstable and biased towards features with higher values.

    Scaling ensures all features contribute equally to the model, preventing one variable from overpowering others due to its numerical magnitude.

    1. Normalization (Min–Max Scaling)¶

    Transforms all values to a 0–1 range.

    Formula:

    \[ y \;=\; \frac{x - \mathrm{min}}{\mathrm{max} - \mathrm{min}} \]

    Where:
    - \( y \) → normalized value
    - \( x \) → original value
    - \( \mathrm{min} \) → minimum value of \( x \) in dataset
    - \( \mathrm{max} \) → maximum value of \( x \) in dataset

    2. Standardization (Z-score Scaling)¶

    Centers the data so the mean = 0 and standard deviation = 1.

    Formula:

    \[ y \;=\; \frac{x - \mu}{\sigma} \]

    Where:
    - \( y \) → standardized value
    - \( x \) → original value
    - \( \mu \) → mean of \( x \)
    - \( \sigma \) → standard deviation of \( x \)

    When to Use¶

    • Normalization → Good for distance-based algorithms like \( k \)-NN, K-Means, Neural Networks.
    • Standardization → Good when algorithms assume normally-distributed data (Linear Regression, Logistic Regression, SVM).

    When to Use¶

    • Normalization: Best for algorithms relying on distances (KNN, K-Means) or neural networks.
    • Standardization: Best for algorithms assuming normality (linear regression, logistic regression, SVM).

    K‑means Clustering¶

    Objective: minimize within‑cluster sum of squares. Lloyd’s algorithm alternates assignment and centroid update.

    K-means Clustering is an unsupervised learning algorithm. Like other clustering algorithms, it tries to aggregate similar objects into groups called clusters. In K-means Clustering, K refers to the number of clusters required. The concept of a centroid, which is the geometric center of a cluster, is used to determine the clusters that K-means finds in the dataset.

    Let’s understand this using an example. Suppose you go to a vegetable shop to buy some vegetables. There, you'll see different kinds of vegetables. One thing you may notice is that the vegetables will be arranged in a group of their type. The carrots and radishes will probably be kept together in one place, onion and garlic will probably be arranged in another place, potatoes will be kept together, and so on. This arrangement resembles a group or a cluster, where each vegetable is kept within its kind of group, forming the clusters.

    Visual (one iteration)¶

    Real‑Time Use Case¶

    Customer micro‑segmentation updated hourly for marketing triggers and content personalization.

    Python Snippet¶

    import numpy as np
from sklearn.cluster import KMeans

X = np.r_[np.random.randn(500,2)+np.array([0,0]),
          np.random.randn(500,2)+np.array([4,4])]
km = KMeans(n_clusters=2, n_init='auto', random_state=42).fit(X)
print("Centroids:\n", km.cluster_centers_)

    Example: K-means on 1D Data¶

    Let’s understand K-means clustering with an example.

    Given:

    \[ N = { 2, 3, 4, 5, 10, 11, 13, 15 } \]

    All points lie on the x-axis.

    Step 1 — Choose K¶

    Let:

    \[ K = 2 \]

    Step 2 — Initialize Centroids Randomly¶

    \[ c_1 = 3, \quad c_2 = 12 \]

    Since all points are on the x-axis (y = 0), the distance between two points is:
    \( d = |x_2 - x_1| \)

    Step 3.1 — Assign Points to Closest Centroid¶

    Data Point Distance to \( c_1 = 3 \) Distance to \( c_2 = 12 \) Cluster Assigned
    2 1 10 c₁
    3 0 9 c₁
    4 1 8 c₁
    5 2 7 c₁
    10 7 2 c₂
    11 8 1 c₂
    13 10 1 c₂
    15 12 3 c₂

    Result after assignment:

    \[ \text{Cluster } c_1: { 2, 3, 4, 5 } \] \[ \text{Cluster } c_2: { 10, 11, 13, 15 } \]

    Step 3.2 — Update Centroids¶

    \[ c_1 = \frac{2 + 3 + 4 + 5}{4} = 3.5 \] \[ c_2 = \frac{10 + 11 + 13 + 15}{4} = 12.25 \]

    Step 4 — Repeat Until Convergence¶

    Repeat Step 3 (assignment and update) until there is no change in centroids.

    Graph Theory¶

    Graphs \(G=(V,E)\) represent relationships (users, items, web pages).

    Visual (mini graph)¶

    Real‑Time Use Case¶

    Fraud rings: Build a transaction graph and compute centrality to flag high‑influence nodes for manual review.

    Python Snippet¶

    import numpy as np
import networkx as nx

G = nx.Graph()
edges = [('A','B'), ('A','C'), ('B','C'), ('C','D'), ('D','E')]
G.add_edges_from(edges)

pr = nx.pagerank(G, alpha=0.85)
print("PageRank:", pr)
